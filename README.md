# Lista de la Compra Espacial

Una aplicación web para gestionar tu lista de compras con temática espacial, usando Supabase como base de datos en la nube.

**URL en producción:** https://jarvismcgopenclaw-hash.github.io/todo-list/

---

## Lo Aprendido en Este Proyecto

### 1. Git y GitHub

| Comando | Qué hace |
|---|---|
| `git init` | Inicializa un repositorio git en la carpeta |
| `git config user.email "..."` | Configura tu email para los commits |
| `git config user.name "..."` | Configura tu nombre para los commits |
| `git add .` | Prepara todos los archivos modificados para el commit |
| `git commit -m "mensaje"` | Guarda los cambios con una descripción |
| `git push` | Sube los commits al repositorio remoto (GitHub) |
| `git status` | Muestra qué archivos han cambiado |
| `git log` | Muestra el historial de commits |
| `git branch -m main` | Renombra la rama a `main` |

**Concepto clave:** Cada commit es como un "punto de guardado" con una descripción de qué cambiaste.

### 2. GitHub CLI (`gh`)

| Comando | Qué hace |
|---|---|
| `gh auth login` | Autenticar tu cuenta de GitHub en la terminal |
| `gh repo create` | Crear un nuevo repositorio desde la terminal |
| `gh auth setup-git` | Configurar git para usar las credenciales de `gh` |

### 3. GitHub Pages

- Servicio gratuito que convierte cualquier repo en una web pública
- Tu web se publica automáticamente en `usuario.github.io/nombre-repo`
- Se actualiza sola cada vez que haces `git push`

### 4. Supabase (Base de Datos)

- **PostgreSQL** open source alojado en la nube
- Plan gratuito: 500MB de almacenamiento
- Crea tablas con SQL y genera automáticamente una API REST

| Concepto | Descripción |
|---|---|
| `anon public` key | Clave para que el frontend hable con la DB (segura para código visible) |
| `service_role` key | Clave maestra, nunca exponer en el frontend |
| RLS | Row Level Security: bloquea acceso por defecto |
| `DISABLE ROW LEVEL SECURITY` | Desactiva RLS para desarrollo rápido |

SQL para crear la tabla de tareas:

```sql
CREATE TABLE tasks (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  name TEXT NOT NULL,
  is_completed BOOLEAN DEFAULT false,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

ALTER TABLE tasks DISABLE ROW LEVEL SECURITY;
```

### 5. HTML

- Estructura semántica: `<header>`, `<section>`, `<footer>`, `<form>`
- Importar CSS externo: `<link rel="stylesheet" href="style.css">`
- Importar JS externo: `<script src="script.js"></script>`
- Importar librerías externas vía CDN

### 6. CSS

- **Variables CSS**: `--primary: #7b2ff7;` → reutilizar con `var(--primary)`
- **Flexbox**: `display: flex` → alinear elementos fácilmente
- **Grid**: `display: grid` → layouts complejos
- **Animaciones**: `@keyframes` + `animation`
- **Gradientes**: `linear-gradient()`, `radial-gradient()`
- **Glassmorphism**: `backdrop-filter: blur(10px)`
- **Responsive**: `clamp()`, `@media`, `minmax()`
- **Hover effects**: `transform`, `box-shadow`, `transition`

### 7. JavaScript

- **DOM**: `document.getElementById()`, `createElement()`, `appendChild()`
- **Eventos**: `addEventListener("submit")`, `addEventListener("click")`
- **Async/Await**: operaciones asíncronas con Supabase
- **Supabase client**: `supabase.createClient(URL, KEY)`
- **Operaciones DB**:
  - Crear: `.from("tasks").insert([{ name: "..." }])`
  - Leer: `.from("tasks").select("*").order("created_at", { ascending: true })`
  - Actualizar: `.from("tasks").update({ is_completed: true }).eq("id", 1)`
  - Eliminar: `.from("tasks").delete().eq("id", 1)`
- **Importar librerías**: `<script type="module">` con `import` desde CDN

### 8. Frontend vs Backend vs Base de Datos

```
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│   FRONTEND      │     │    BACKEND      │     │   BASE DE DATOS │
│                 │     │                 │     │                 │
│  Lo que ve el   │◄───►│  Procesamiento  │◄───►│  Almacenamiento │
│  usuario        │     │  de datos       │     │  persistente    │
│                 │     │                 │     │                 │
│  HTML/CSS/JS    │     │  Node.js,       │     │  PostgreSQL,    │
│                 │     │  Python, Ruby   │     │  MongoDB        │
└─────────────────┘     └─────────────────┘     └─────────────────┘
```

**En este proyecto** no usamos backend propio: el frontend habla directamente con Supabase gracias a la API REST automática.

### 9. Flujo de Trabajo Completo

```
1. Haces cambios en los archivos (HTML, CSS, JS)
2. git add .                     ← Preparas los cambios
3. git commit -m "descripción"   ← Guardas una versión
4. git push                      ← Subes a GitHub
5. GitHub Pages actualiza automáticamente tu web
```

### 10. Depuración de Bugs

- Abre la web en tu navegador
- Pulsa `F12` → pestaña **Console**
- Los errores aparecen en rojo con la línea exacta del problema
- Los warnings (como los de PostHog) son informativos, no bloquean la app
